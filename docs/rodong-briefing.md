# 노동신문 브리핑 작성 지침

매일 `app/data/rodong.json`의 `days`에 그날 『로동신문』 브리핑 하나를 추가한다. 사이트의 `/rodong`에 자동으로 나타난다.

## 분야

| field | 분야 | 주로 보는 내용 |
|---|---|---|
| `politics` | 정치 | 김정은 활동, 당·국가기구 회의, 대외관계·외교, 군사 |
| `economy` | 경제 | 농업·공업·건설, 지방발전 정책, 경제 캠페인 |
| `society` | 사회 | 보건·문화·법·주민생활, 사상교양, 근로단체 |
| `women` | 여성 | 여성동맹, 여성 근로자·모범 사례, 가정·모성 담론 |
| `education` | 교육 | 학교교육, 교원, 대학·과학, 원격교육 |
| `youth` | 청(소)년 | 청년동맹·소년단, 청년 돌격대·탄원, 청년 담론 |
| `health` | 보건의료 | 병원·의료진, 의약품 생산, 예방·위생, 아동 영양 |
| `disability` | 장애인 | 장애인 정책·교육·체육, 영예군인, 장애인 관련 국제 활동 |
| `climate` | 기후환경 | 기후변화·이상기후, 재해, 산림·국토관리, 자연에네르기, 환경보호 |

한 기사가 여러 분야에 걸리면 가장 중심이 되는 분야 하나에 넣고, 필요하면 `note`에 다른 분야와의 관련을 적는다.

## 형식

```json
{
  "date": "2026-10-22",
  "overview": "그날 지면 전체를 한 문장으로 요약",
  "items": [
    {
      "field": "women",
      "title": "이슈를 한 줄로",
      "summary": "기사 내용 요약(2~4문장). 북한의 표현은 따옴표로 그대로 인용한다.",
      "note": "(선택) 이전 보도와 달라진 점, 정책적 함의 등 짧은 해석",
      "sources": [{ "headline": "기사 원제목", "page": 4, "url": "기사 주소" }]
    }
  ]
}
```

## 원칙

- 실제로 그날 지면에 실린 기사만 쓴다. 기사를 확인하지 못했으면 그 분야는 비워 두고, 지어내지 않는다.
- 기사 원문을 옮겨 싣지 않고 요약과 짧은 인용만 쓴다. 출처(제목·면·주소)는 반드시 남긴다.
- 요약(`summary`)은 보도 내용, 해석(`note`)은 분석으로 구분한다.
- 분야마다 0~3건, 그날 가장 의미 있는 기사 위주로 고른다.
- 추가한 뒤 `pnpm test`로 빌드가 통과하는지 확인하고 `main`에 올린다.

## 주간 하이라이트

`app/data/rodong-weekly.json`에 한 주(월요일 날짜를 `week`로)의 흐름을 한 문장으로 적는다. 적지 않은 주는 그 주 첫 브리핑의 요약이 대신 보인다.

## 조선중앙통신 브리핑

같은 형식으로 `app/data/kcna.json`의 `days`에 더한다(사이트 `/kcna`). 주간 하이라이트는 `app/data/kcna-weekly.json`. 출처의 `page`는 비워 두고, 보도 제목을 `headline`에 적는다.

## 월별 리포트용 세부 주제 (topic)

교육·여성·청(소)년·장애인·보건의료 항목에는 `topic`을 하나 붙인다. `/rodong/monthly/<YYYY-MM>` 이 이 값으로 주제 분포를 센다. 해석 글은 `app/data/rodong-monthly.json`에 달마다 쓴다.

- 교육: 교원·교원양성 / 교육정책·교육강령 / 학교시설·학생물자 / 고등교육·대학 / 지역 교육·격차 해소 / 학생 교양 / 국제·총련 교류
- 여성: 녀맹 조직·행사 / 노동 진출·탄원 / 여성 체육 / 모범·미담
- 청(소)년: 탄원·진출 / 청년동맹·청년중시 사업 / 사상·기념 행사 / 학생·소년단·아동 / 모범·수기 / 국제·총련 교류 / 청년 체육
- 장애인: 장애인 체육 / 영예군인 복지·일터
- 보건의료: 병원·의료봉사 / 의료일군 미담 / 제약·고려약·의료기구 / 위생·방역·건강관리 / 의학교육·보건과학 / 해외 보건·전염병 / 영양·육아

## 자동 갱신되는 분석 페이지

브리핑을 `app/data/rodong.json`에 더하고 빌드하면 아래가 저절로 바뀐다.

- `/rodong/monthly/<달>`: 새 달이 생기면 페이지가 추가되고 집계·그래프가 채워진다. 해석 글은 `app/data/rodong-monthly.json`에 따로 쓴다.
- `/rodong/report/education`: 시작일부터 최신 브리핑까지 집계한다. 달별 비교표, 날짜 그래프, '이후 보도' 국면, 최근 보도 7일치가 늘어난다.
- `/rodong/focus/education-2026-autumn`: `curatedUntil` 뒤 브리핑에서 쟁점별 `match` 주제어가 맞는 항목이 '자동' 표시로 보도 흐름과 추이표에 들어간다.

`topic`을 달지 않은 항목은 `app/rodong/data.ts`의 규칙으로 주제를 추정하므로, 정확한 집계를 위해 교육·여성·청(소)년·장애인·보건의료 항목에는 가능하면 `topic`을 직접 단다.
